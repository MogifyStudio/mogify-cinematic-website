# Mogify Studio — Cinematic Website

**Live demo:** [https://mogify-cinematic.sites.tab.bot/](https://mogify-cinematic.sites.tab.bot/)

A dark, immersive, cinematic version of the **Mogify Studio** business website (Karachi, Pakistan). Scrolling tells the story in chapters, with a WebGL particle hero built from the real Mogify logo, kinetic typography and the same packages and Project Planner as the business site.

## Features

- **Particle hero**: the original Mogify logo rebuilt at runtime from ~15,000 glowing particles (~7,500 on phones); touch/mouse scatters them, the logo tilts with the phone gyro on Android
- **Scroll chapters**: particles morph into a wave, sphere and star field per section and re-form the logo at the final call to action
- Kinetic headline, word-by-word manifesto reveal, scroll-speed marquees, horizontal work reel, outline process numbers
- **Dark packages** with a service switcher (9 services × 3 tiers), comparison and add-ons; "Get a quote" opens WhatsApp with the package named
- **Project Planner** (7 steps) that sends the full brief to WhatsApp or email
- Desktop extras: custom cursor, magnetic buttons, teal page-transition wipe; smooth scrolling and film grain; a still version for reduced-motion users
- **25 pages** with per-page SEO, Open Graph, JSON-LD, sitemap.xml and robots.txt

## Tech stack

Static HTML/CSS/JS generated by a Python build script. Hand-written WebGL (`gl.js`), GSAP + ScrollTrigger and Lenis (bundled in `assets/vendor/`). Font: Manrope. Brand colours: teal `#00A99D`, navy `#121927`.

- No backend: forms and the planner send briefs through `wa.me` (WhatsApp) and `mailto:` links.

## Run locally

Requires Python 3.8+ (standard library only).

```bash
git clone https://github.com/MogifyStudio/mogify-cinematic-website.git
cd mogify-cinematic-website

# preview the site (supports the clean URLs used on the live site, e.g. /about)
python3 serve.py            # → http://localhost:8000

# regenerate the pages after editing content.py / work.json / build.py
python3 build.py
```

A plain `cd site && python3 -m http.server` also works for the home page, but pretty URLs like `/about` need `serve.py` (or any host that maps `/about` → `about.html`).

### Tests

```bash
node --test test/site.test.js
```

## How to change prices

All prices (and the WhatsApp number / email the site uses) live in **one object**: `site/assets/js/config.js` → `window.MOGIFY`.

```js
window.MOGIFY = {
  whatsapp: "923232194013",
  email: "mogifystudio@gmail.com",
  noPriceText: "Price on request",
  prices: {
    web:  { starter: "PKR 45,000", growth: null, premium: null },  // prices[serviceId][tierId]
    logo: { starter: null, growth: null, premium: null },
    // service ids: web, logo, brand, uiux, motion, anim3d, social, book, video
    // tier ids:    starter, growth, premium
  },
  addons: { "extra-page": null, "urdu-version": null, /* ... */ }
};
```

- `null` shows **"Price on request"**; a string is shown exactly as written (`"PKR 45,000"`, `"From $299"`).
- No rebuild needed — just redeploy the `site/` folder.

## How to change the domain

Open `build.py` and change the single line:

```python
BASE_URL = "https://mogify-cinematic.sites.tab.bot"   # no trailing slash
```

then run `python3 build.py`. Canonical URLs, Open Graph tags, JSON-LD, `sitemap.xml` and `robots.txt` all follow it.

## Deploy

`site/` is a plain static folder — upload it to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages with clean-URL support, cPanel, etc.). The live demo is published as `mogify-cinematic`.
